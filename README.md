# isa-sdk

Unified Go SDK for [ISA APIs](https://docs.isaapi.com).

This repository is a **read-only mirror**. Do not file PRs here — the canonical source lives at [`Software-Automation-Holdings-LLC/isa-platform`](https://github.com/Software-Automation-Holdings-LLC/isa-platform/tree/main/packages/go), and the `sdk-publish` workflow synchronizes this mirror on every release tag.

## Install

```sh
go get github.com/isa-sdk/sdk
```

## Documentation

See [docs.isaapi.com](https://docs.isaapi.com).

## Versioning

Tags follow [Semantic Versioning](https://semver.org). Module versions are visible at [pkg.go.dev/github.com/isa-sdk/sdk](https://pkg.go.dev/github.com/isa-sdk/sdk).
